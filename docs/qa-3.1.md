# v3.1 界面与验证记录

2026-11-18 验证。截图取自最终 APK 解包后的页面，账单、工时和待办均为人工样例。[查看首页、工时日历和记账弹窗](previews/v3.1.webp)。

## 日常操作

- 首页日期旁展示当前主题的插画，点日期或插画进入当天日历。本月支出、收入、结余并排，眼睛按钮紧邻金额。常用入口下方依次是待处理、本月计划、工作和最近账单。宽屏采用双栏。
- 新装时可从首页直接设置预算和月存钱额。验证保存后立即出现实际进度。切换账本后，首页收支与点入的月报采用相同账本范围，月计划保留「全部账本」标识。
- 工时日历上方显示当前范围的已记工时、已计工资、区间日均工资和出勤天数。已验证自然月与工资周期往返切换。资产页同时展示总资产、总负债和净资产，负债明细可展开。
- 记账先选类型、填金额，再从下拉框选账本。「一句话记账」仍可预览、修改和保存。已验证昨日账、转账扣取手续费、出差垫付的归属账本，以及只改备注并保存一笔旧账。
- 修复编辑停用账户旧账时可能自动选中另一账户的问题。浏览器回归用例同时归档原账本、停用原账户，再核对保存后的账单 ID、类型、日期、金额、账本、账户及备注。新记账仍只列出可用账户和账本。[记账回归用例](../tests/browser/entry-form.cjs)。
