# 消费预算与存钱（v2.31）

全账本月消费上限与月存钱计划存入 `moneyPlans`，以自然月为单位。`repeat` 从所选月份向后沿用，新的月度设置覆盖此前规则，不回写历史月份；停用保存 0 值规则，防止旧计划重新出现。原有账本／分类预算保留，各口径不相加。

支出按 `out` 汇总，信用卡消费计一次，转账、还款与出差垫付／报销不计个人消费。编辑账单先扣除原记录再预览新金额；新增或增加支出超限时二次核对，取消不写入。已经花出去的钱仍允许如实记录。AI 直接记录的支出在结果中注明超限。

主要存钱账户默认识别现有建行卡，可手动更换。`savingGoals` 每个目标关联一个资产账户，同一账户不能重复关联；目标进度来自完整账户余额。月存钱进度合并主要存钱账户与所有目标账户后去重，汇总其当月净流入；目标间转账相互抵消，期初余额不计本月新存的钱。删除目标保留账户和流水；主要存钱账户的独立设置保留。所有新数据随原完整 JSON／云备份保存与恢复。

预算起步参考根据用户提供的联培、月薪约 6000、企业提供午饭设计：消费 2000、存钱 3000、机动 1000。它是可编辑的表单建议，必须在应用中保存才启用，不假设住宿或其他开销为零。优先依据实际到手收入、完整月份花销调整。参考 [Consumer.gov：Making a Budget](https://consumer.gov/your-money/making-budget) 关于按实际收支制定预算、将存钱纳入计划的方法；金额是本应用的情景建议，并非来源推荐。

主要验收：跨账本／跨月、闰月日额度、账单编辑和取消、信用卡与报销去重、存取修改删除、备份恢复与非法数据拒绝、存储失败原子回滚、隐藏金额及移动端布局。
