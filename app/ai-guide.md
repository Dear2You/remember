## 从哪里开始

底栏有「首页」「资产」「工时」「记一笔」「账单」「时光」「我的」。首页先看本期工资与出勤，再看自然月收支和今日安排；展开「生活工具」进入备忘录、打卡、专注、订阅等页面。点应用顶部的对话图标进入 AI 助手。

## 记账与查账

- 点「记一笔」，选支出、收入或转账/还款，填写金额、账户、日期后保存。支出和收入支持两级分类。刷信用卡记一次支出，之后还款用转账。转账和还款只影响账户余额。
- 支出中的「实际扣款账户」决定余额从哪里扣。「支付渠道」可选微信、支付宝等。例如支付宝扣中国银行，就选中国银行作为实际扣款账户、支付宝作为渠道。在「资产」点某个资产账户，输入银行或支付 App 的实际余额可比较差额；点最近流水可更正，期初余额在「查看账户及期初设置」核对。
- 在「记一笔 → 一句话记账」或助手中输入“昨天微信午饭 28 元”。本机会先显示核对卡，可点「修改」，点「确认记账」才入账。在助手里记的这类账有「编辑账单」和「撤销」。
- 在「账单」切换「收支分析」「流水明细」「账单日历」。可换账本和周期、筛选账户和分类、搜索流水。报表可看折线、柱状、分类占比和同期对比。日历默认显示收支，也可切换支出、收入或结余。点日期看当天明细，点流水可编辑或删除。
- 离线提问“这个月花了多少钱？”“上月收支”“本月哪类花得最多？”“本月哪笔支出最大？”按账单页选定的账本统计。

## 结束出差模式

点「资产 → 出差报销」，打开标着「出差中」的行程。在「记垫付」和「登记到账」两个按钮下面点「结束出差模式」。如果这里显示「设为当前出差」，这趟行程已经退出。之后用「记一笔」恢复日常记账，旧行程仍可收款。

## 出差垫付与报销

- 在「资产 → 出差报销 → 新建行程」输入行程名称、选账本，点「开始出差」。同一时间有一个当前行程。出差期间「记一笔」的支出默认记入该行程，一笔个人消费可取消勾选「记为出差垫付」。行程里也可直接点「记垫付」。
- 公司打款时，打开对应行程，点「登记到账」，核对收款账户、日期和实收金额。金额默认是剩余垫付款，分批收款就改为本次实收。待报销等于累计垫付减去已到账。两者都会更新账户余额，个人收入、消费和预算另算。
- 点行程明细中的一笔垫付或到账可修改日期、账户、金额和备注。改动后，任一天的累计到账都不能超过当时的累计垫付。
- 行程内可「标记已提交报销」或撤回标记，部分到账和已结清由金额自动判断。「导出本次明细」只导出这趟行程的 CSV。垫付可修改费用分类和支付渠道。「票据照片 → 添加照片」支持 JPG、PNG、WebP，压缩后随完整备份保存，点缩略图查看或删除；CSV 只含文字明细。

## 选择或更改收款账户

在「资产 → 出差报销 → 对应行程 → 登记到账」，直接点「收款账户」下的银行卡、支付宝、微信零钱或其他已启用的资产账户，再保存。首次有多个可选账户时需自己选；只有一个时会选中它。下次到账会沿用上次选的收款账户，每笔都可以改选。已记错的，点原来那笔「报销到账」，换账户后保存，金额会从原账户移到新账户。要添加自己的工资卡，先去「我的 → 账户管理」添加资产账户。

## 删除报销到账

在「资产 → 出差报销」打开对应行程，找到要删的「报销到账」，点这笔右侧的「删除」。按日期、收款账户和金额核对，确认框会显示删除后的待报销金额。点「取消」保留原记录，点「删除」会撤回这笔到账对账户的影响，其他批次照常保留。垫付记录也支持删除，如果已有到账依赖那笔垫付，先核对并更正相应的到账记录。

## 资产、预算与会员订阅

- 「资产」可看账户余额、净资产、预算和转账/还款。「我的 → 账本与预算」可进入账本管理、预算设置、账户管理、分类管理。选定具体账本后，可设月总预算和一级支出分类预算。
- 「资产 → 会员支出」或「首页 → 会员订阅」可新增订阅，点已有订阅可编辑或删除。新增默认新加坡元，另有人民币、美元、欧元、英镑、港元、日元、澳元、加元、马来西亚林吉特、新台币和泰铢。每笔保留原币金额，月合计按人民币显示。在「折算汇率」选币种，然后「在线更新」或「手动设置」。有币种缺汇率时，合计显示「待补汇率」。

## 工时与薪资

在「工时」点日历中的日期，按项目记录当天工作。「按时薪」填小时数，可用项目时薪或默认时薪。「按日薪」填日薪和计薪天数，半天填 0.5，实际工时选填。同一天可有多个项目，也可混合两种计薪方式。日历格展示每日工时与已计工资，点当天记录可编辑，长按记录可删除。「时薪设置」可改项目和默认时薪。

- **月薪按工作日折算**：在「工时 → ＋ 月薪方案」填项目、完整一期正常出勤工资、计薪周期和归属月份。归属月份是区间结束的月份，例如选择“上月21日到本月20日”，2026年10月方案覆盖9月21日至10月20日，下一期从10月21日开始，日期不重叠。可选自然月或22日至次月21日。不确定时保留“暂未确认，先按自然月估算”，助手和首页都会说明区间待确认。
- **入职起算与发薪日**：工资方案填完整「入职起算日」，此前不计薪、不算缺勤。整期应出勤日期仍作分母，首次不足一期按入职后的工作日比例估算。在首页点「距发薪日还有…」可设置每月发薪日，默认21日；它不决定计薪区间、不创建收入，也不是已安排的系统通知。用户只说入职日或发薪日时，不能推断公司的考勤截止日已确认。
- 工作日规则可选「法定节假日及调休」，内置2026、2027年安排，包含调休周末；点日期按公司安排调整。未知年份选周一至周五并自行核对。方案逐期创建，新一期带入之前的项目、工资、入职日和已确认周期，不会自动补记出勤。
- 日薪参考值等于完整一期工资除以本期应出勤天数。点工时日历当天的月薪项目，选「出勤一天」「出勤半天」「缺勤一天」。未填的过去日期待确认，未来只作预计，不自动扣钱。预计工资按剩余日期正常出勤估算，已计工资只包含确认记录，完整一期全勤精确等于月薪。金额按累计计薪比例分摊到分，补记早期日期时后续日金额可能微调一分钱。
- 旧固定日薪可在方案中勾选「将区间内同项目的旧日薪重新折算」，核对金额后保存，只转换所选区间。已有月薪方案更改周期时，点「计薪设置」，改周期后进入「预览计薪周期调整」：先查看此项目全部日薪、月薪记录的新区间与金额，再确认。保留工作记录的日期、备注、工时，时薪记录不动；未确认的自定义排班需重新核对。原工资收入保留金额、账户和日期，解除旧周期关联并标记待核对，需要在新周期重新关联，避免自动猜测归属。
- 已有出勤的日期若要从方案移除，先在当天「撤销当天确认」。删除方案会删除其月薪出勤，收入账单保留。月薪卡「批量补记」可多选截至今天且入职后的未记工作日，统一记整天、半天或缺勤，保存前核对数量和金额。同项目同日已有普通记录时先转换或核对。
- 工时页面可切「工资周期 / 自然月」。跨月日历标出完整起止日期，周期首日及每月1日带月份，点当天看明细。按期的工资卡可能与自然月区间不同，始终以卡上的起止日期为准。「项目分布」可切工资、出勤天数和已填小时。
- 「工资到账」按项目和工资归属月份核对，月薪项目使用方案的完整起止日期。「登记到账」选择收款账户及实际到账日期，支持分批；已记过的收入用「关联已有收入」。跨月发薪仍可归属原周期，收入报表按实际到账日统计。点到账可编辑，「解除关联」保留账单，「删除到账」撤回收入及账户影响。未关联的收入不会自动认定已结清。
- 首页显示本期预计工资、已确认工资、已关联到账、已计待收及待确认出勤；无当前方案时展示自然月已记工资并提供设置入口。「本月收支」始终按自然月与实际收付款日期计算，单独于工资估算；有待报销或订阅日期时显示跟进事项，生活工具默认折叠。
- 助手可离线查询本期或上期工资，逐项目列出起止日期、已计、已关联到账、待收和预计。明确说“自然月”时只汇总该月的工作记录。计薪方案、出勤确认、周期调整和到账关联需用户按上述入口操作，助手不能伪称已修改或重复用普通收入、工时动作代替。

## 订阅扣款与提醒

订阅金额按「每次扣款原价」填写，周期可选每月、每季度、每年。首页和资产按月均折算；暂停订阅不计固定支出。设置下次扣款日，可开启当天或提前 1、3、7 天上午 9 点通知。实际扣款后点「已扣款，登记支出」，核对人民币实扣金额、账户和分类；已经记过的可选择已有支出关联，不会重复记账。保存后推进下次日期，删除最新一期扣款账单可恢复对应待扣日期。删除订阅保留历史扣款账单。

## 时光、备忘与习惯

- 「时光」可切换「日历」「今日」「事项」「更多」。日历点日期可添加日程或待办，今日页可完成待办、打卡。事项支持日期、时间、重要或紧急标记、列表与四象限，以及每日、每周或每月重复。
- 日程编辑可开启「提醒我」，选开始时或提前 5、15、30、60 分钟或 1 天。每周重复的日程继续提醒；修改、关闭或删除会同步排程。日程仍是计划，实际工作在工时页确认。
- 「时光 → 更多」可打开备忘录、习惯打卡、番茄专注、倒数日/纪念日。备忘录支持文本、清单、搜索和置顶。习惯可在打卡月历查看。专注可选番茄钟、正计时或倒计时。倒数日可设每年重复。

## 手机提醒、闹钟与日历

安卓上编辑待办或备忘，填日期和时间，勾选「到时通知我」并保存。收不到时看「我的 → 手机提醒」，检查「通知设置」「准时提醒」。展开「锁屏提醒检查」可查看排程和最近提交通知的时间，运行「一分钟测试」。在支持的手机上，可在编辑页选「另设手机闹钟」或「保存并交给手机日历」，在系统应用里确认；之后改期或取消这些外部提醒也在相应系统应用操作。

## 数据、显示与更新

- 在「我的」展开「数据」。安卓可查看本地自动备份，或点「坚果云自动备份 → 设置」，用坚果云邮箱和第三方应用密码连接。连接后，变动会排队上传，断网后可重试。换机时连接同一账号，选择云端副本并确认恢复。备份包含账单、生活记录和对话，AI Key 留在本机。
- 「导出完整备份」生成 JSON，可在「导入备份」预览并确认恢复。「导出 CSV 账单」用于查看流水。清空本机数据或恢复备份需在界面里确认。
- 「我的 → 显示」可隐藏金额并切换浅色、深色或跟随系统。「我的 → 应用更新 → 检查更新」可检查新版，按「下载并安装新版」后在安卓安装界面确认。

## AI 助手与操作范围

- 离线可问“还有多少报销没到账”“本月工资汇总”“家教结清了吗”“下周有哪些扣款”。报销按全部行程或指定行程，工资按本月或上月已记项目和已关联收入，扣款按已设置的日期查询。查询不执行记账。月薪方案、出勤确认、工资结算关联和订阅扣款由用户按对应界面操作，助手不可用普通收入或工时动作替代这些操作。
- 在「我的 → AI 助手设置」填写接口地址、模型和 API Key，测试连接后保存。联网对话会携带本手册、近期对话及应用提供的数据摘要。助手页可新建、切换和删除历史对话。离线可使用简单记账、月度查账及手册中的操作指引。
- 联网助手能按明确指令记人民币收支、转账或还款、建待办、建文本备忘、建习惯、为已有习惯打今天的卡、记时薪或日薪工时。聊天操作卡可撤销支持的操作。普通待办动作可设日期、重要和紧急；需要具体时间、重复或系统提醒时，再到事项编辑页设置。
- 用户问“在哪”“怎么用”时，直接给出这版界面的按钮和路径。开始或结束出差、登记或删除报销到账、调整汇率、恢复备份、设置手机闹钟等由用户在对应页面操作。解释动作时只给步骤；执行结果以实际保存的记录和操作卡为准。
