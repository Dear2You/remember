## 从哪里开始

底栏有「首页」「资产」「工时」「记一笔」「账单」「时光」「我的」。首页可看本月收支、工作摘要、待处理事项和最近账单。「记工时」直接打开当天记录，「记待办」添加今日事项，「备忘录」「出差报销」可直接进入；展开「更多工具」进入订阅、打卡、专注、倒数日等。点最近账单可编辑，「全部」打开相应月份的流水。点应用顶部的对话图标进入 AI 助手。

## 记账与查账

- 点「记一笔」，选支出、收入或转账/还款，填写金额、账户、日期后保存。支出和收入支持两级分类。刷信用卡记一次支出，之后还款用转账；转账本金只影响账户余额，手续费另计支出。
- 支出中的「实际扣款账户」决定余额从哪里扣。「支付渠道」可选微信、支付宝等。例如支付宝扣中国银行，就选中国银行作为实际扣款账户、支付宝作为渠道。在「资产」先点「资产账户」一行或右侧下拉箭头展开，再点账户，输入银行或支付 App 的实际余额可比较差额；点最近流水可更正，期初余额在「查看账户及期初设置」核对。账户列表默认收起，点同一行可收回；「管理账户」可新增、改名、更换图标或停用账户。
- 在「记一笔 → 一句话记账」或助手中输入“昨天微信午饭 28 元”。本机会先显示核对卡，可点「修改」，点「确认记账」才入账。在助手里记的这类账有「编辑账单」和「撤销」。
- 在「账单」依次切换「流水明细」「收支分析」「账单日历」，首次进入默认流水明细。可换账本和周期、筛选账户和分类、搜索流水。报表可看折线、柱状、分类占比和同期对比。日历默认显示收支，也可切换支出、收入或结余。点日期看当天明细，点流水可编辑或删除。

## 转账、提现与手续费

- 点「记一笔 → 转账/还款」，填写金额、转出和转入账户，再填手续费（无手续费可留空）。额外扣除：转 1000、手续费 1，扣款 1001、到账 1000。金额内扣除：转 1000、手续费 1，扣款 1000、到账 999。按实际凭证选方式，不推测平台费率；填完可直接核对实际扣款与到账。
- 主转账流水的金额始终是实际到账 / 抵扣欠款本金。另有一条「转账手续费」支出，同步预算、分类、图表和资产。点击手续费会打开对应转账编辑；修改或删除转账会一起改删费用。将手续费清空会移除该笔关联费用。
- 存钱页登记存入、取出也支持手续费。AI 明确转账指令可提供 fee 与 feeMode（extra 或 deduct），扣费方式不清楚先询问，撤销转账同时撤销费用。手续费不能为负、不能超过内扣金额；还款本金不能超过当前记账欠款。
- 收支走势右上角切「折线」「柱状」，点图例可单独看收入或支出；点图中日期或下方左右箭头可读金额，点「日期 明细」查看该日流水。分类环形图可切收入和支出，点色块或分类行展开明细。隐藏金额时同时隐藏图表。山水页眉是随应用附带的装饰，离线也会显示，不需要点击操作。
- 离线提问“这个月花了多少钱？”“上月收支”“本月哪类花得最多？”“本月哪笔支出最大？”按账单页选定的账本统计。

## 结束出差模式

点「资产 → 出差报销」，打开标着「出差中」的行程。在「记垫付」和「登记到账」两个按钮下面点「结束出差模式」。如果这里显示「设为当前出差」，这趟行程已经退出。之后用「记一笔」恢复日常记账，旧行程仍可收款。

## 出差垫付与报销

- 在「资产 → 出差报销 → 新建行程」输入行程名称、选账本，点「开始出差」。同一时间有一个当前行程。出差期间「记一笔」的支出默认记入该行程，一笔个人消费可取消勾选「记为出差垫付」。行程里也可直接点「记垫付」。
- 公司打款时，打开对应行程，点「登记到账」，核对收款账户、日期和实收金额。金额默认是剩余垫付款，分批收款就改为本次实收。待报销等于累计垫付减去已到账。两者都会更新账户余额，个人收入、消费和预算另算。
- 点行程明细中的一笔垫付或到账可修改日期、账户、金额和备注。改动后，任一天的累计到账都不能超过当时的累计垫付。
- 行程内可「标记已提交报销」或撤回标记，部分到账和已结清由金额自动判断。「导出本次明细」只导出这趟行程的 CSV。垫付可修改费用分类和支付渠道。「票据照片 → 添加照片」支持 JPG、PNG、WebP，压缩后随完整备份保存，点缩略图查看或删除；CSV 只含文字明细。

## 选择或更改收款账户

在「资产 → 出差报销 → 对应行程 → 登记到账」，直接点「收款账户」下的银行卡、支付宝、微信零钱或其他已启用的资产账户，再保存。首次有多个可选账户时需自己选；只有一个时会选中它。下次到账会沿用上次选的收款账户，每笔都可以改选。已记错的，点原来那笔「报销到账」，换账户后保存，金额会从原账户移到新账户。要添加自己的工资卡，先去「我的 → 账户管理」添加资产账户。

## 删除报销到账

在「资产 → 出差报销」打开对应行程，找到要删的「报销到账」，点这笔右侧的「删除」。按日期、收款账户和金额核对，确认框会显示删除后的待报销金额。点「取消」保留原记录，点「删除」会撤回这笔到账对账户的影响，其他批次照常保留。垫付记录也支持删除，如果已有到账依赖那笔垫付，先核对并更正相应的到账记录。

## 资产、预算与会员订阅

- 「资产」可看账户余额、净资产、预算和转账/还款。「我的 → 账本与预算」可进入账本管理、预算设置、账户管理、分类管理。选定具体账本后，可设月总预算和一级支出分类预算。
- 「资产 → 会员订阅」或「首页 → 更多工具 → 会员订阅」可新增订阅，点已有订阅可编辑或删除。新增默认新加坡元，另有人民币、美元、欧元、英镑、港元、日元、澳元、加元、马来西亚林吉特、新台币和泰铢。每笔保留原币金额，月合计按人民币显示。在订阅页下方展开「折算汇率与币种」，选择币种，然后「在线更新」或「手动设置」。有币种缺汇率时，合计显示「待补汇率」。

## 预算与存钱

- 在「首页 → 预算与存钱」「资产 → 预算与存钱」或「我的 → 预算与存钱」进入。按自然月、所有账本统计个人支出，出差垫付、报销到账、转账与还款本金不占消费上限，手续费和信用卡消费计入。账本或分类预算是另一个观察口径，与全账本消费上限不相加。
- 点「调整计划」，填月消费上限和计划存下的金额。勾选「每月沿用」从所选月起生效；不勾选只适用于该月并停止此前沿用规则，后续月份需重新设置。停用计划保留以前月份和账单。每天可花额度按剩余预算除以含今天的剩余日历天数计算，超支时为 0；历史月份不显示每天额度。
- 同一计划可填购物、外卖、奶茶饮品专项额度，包含在总消费上限内，空白或 0 为不限。按分类识别；餐饮备注含外卖、奶茶、咖啡也会识别，同一笔只归一组（饮品优先于备注中的外卖）。点「留意这几笔」核对明细和修改分类。记账时专项超限也会提醒，转账手续费不占这些专项额度。
- 「填入这套建议」是可调整的联培起步方案：企业提供宿舍及午饭、主要步行时，消费 2000，其中购物 500、外卖 200、饮品 100；其余参考做饭吃饭 700、交通 100、其他 400。按实际到账约 6000，计划存钱 3000、机动 1000；有历史欠款先留还款金额。保存才生效，同时补充餐饮下的买菜做饭、奶茶饮品分类。先记录一个完整月再调整，不保证固定储蓄金额，也不会自动操作银行卡。
- 联培生活起步建议：按月收入约 6000、企业提供午饭，消费 2000、存钱 3000、留 1000 机动。点击「填入这套建议」只填写表单，保存后生效。住宿、交通支出较多或实际到账不足时应调整。这是可修改的起步参考，不代表用户已经确认、没有其他支出或一定能达到。
- 在「主要存钱账户」选择建行卡。未指定时识别名称含“建行”“建设银行”或“CCB”的资产账户；可以更换或选「不单独指定」。支出默认优先消费账户，仍可手动选择存钱账户。指定账户及所有目标账户合并去重计算存钱进度：本月收入、转入减去支出、垫付和转出；两个存钱账户之间转账不会重复增加。期初余额只计目标总进度，不计本月新存金额。月结余与实际存钱进度分开显示。
- 点「新目标」，填写名称、总金额和可选日期，优先关联建行卡，也可新建初始余额为 0 的独立存钱账户。同一账户只关联一个目标，账户全部余额作为目标进度。已有目标的账户不在目标编辑页变更，避免把另一张卡的余额误当同一目标。
- 点「存入一笔」或「取出」，选择另一账户、金额和日期，记录已经完成的转账。App 只记账，不会真的操作银行卡。转账同步账户余额和目标进度，不重复计收入、支出。点「流水」再点某笔可编辑或删除；删目标保留账户与流水，主要存钱账户的独立设置也保留。
- 记账弹窗实时显示保存后的剩余额度。新增支出或增加金额导致超预算时需要再次核对；已发生的消费仍可选择「仍然记下」，不能为了不超预算而漏记。订阅扣款也核对预算，AI 直接记入的支出会在结果中提示超预算。可直接问助手“本月还能花多少”“存钱进度”，离线也能查。助手可以查询和解释，不能声称已代设计划、代建目标或完成银行转账。

## 白条与信用消费

- 「预算与存钱 → 白条与信用消费 → 添加」可建立京东白条等负债账户。建账欠款只填尚未在 App 记过的历史欠款，不填信用额度；已逐笔记过的消费不能再放进期初欠款。同名账户不重复创建，已有账户去「核对账户 / 历史欠款」。
- 下单时点该账户「记消费」，或记一笔支出并选白条账户，立即计入消费、购物预算并增加欠款。还款点「记还款」，选实际扣款的银行卡，记为转账；不重复算消费。App 不会读取京东订单、自动扣款或设置白条限额。
- 首页显示本月信用消费、当前全部待还。预算页按账户显示消费、还款和流水，支持点记录修改或删除。当前待还包含历史未还，是 App 已记的账户余额，不等于京东本期账单或当月应还。利息、分期费按实际发生另记支出；转账手续费可用上面的关联方式。

## 主题与外观

- 在下方「主题配色」下拉框选择原配、海蓝、青绿、雾紫、胭粉或暖杏，只调整界面底色与点缀色，背景插画保持主题原画。每个主题分别记住配色，选「原配」恢复该主题默认颜色。收入一直使用绿色、支出使用红色，不能根据某个图表分类的色块判断收支类型。
- 「碧海晴空」使用柔和面积曲线和海蓝分类层次；「未来回响」使用细网格、微光折线、方正柱图、带刻度的环形图及更利落的字体。图表的数字、金额口径、扇区占比及点日期看明细的操作保持一致。主题不提供实时行情或新的统计数据。
- 「松间晨雾」搭配植物感色阶、细横线图表和年轮细节；「落日余温」搭配暖色分类、柔和面积曲线与双线环形图。装饰不改变统计数据或扇区占比。
- 「水墨清夏」「碧海晴空」「松间晨雾」「落日余温」支持下方「明暗 → 跟随系统／浅色／深色」。「星空彼岸」「未来回响」固定夜间外观，切回其他主题后恢复原明暗偏好。主题和各主题配色随完整备份恢复；旧备份缺少配色时使用原配，不影响已有账单、工资和账户。助手可说明路径，不会直接修改主题。

## 工资自动续期

- 已有「企业上班」月薪方案从旧版升级时默认开启。进入「工时 → 企业上班卡片底部 → 自动续期 → 管理」可核对状态、下一期区间，或暂停／恢复。新建或编辑「计薪设置」时，也可勾选「按当前工资和周期自动续期」。其他项目默认不开启，可逐项选择。
- 沿用这个项目最近一期的月薪、已确认计薪周期和入职日，按新一期法定节假日及调休重新排工作日。例如21日周期，10月21日至11月20日后接11月21日至12月20日；归属月份按区间结束月。不会改成自然月或把发薪日当作周期。
- 打开应用时准备下一期；跨日回到前台或保持应用可见时也会检查。长时间没打开，下次进入会补齐缺少的区间，再准备下一期，不用逐月创建。重复进入不会多建。应用关闭时不依赖系统后台定时任务。
- 自动生成的方案标记「自动生成」，按整期工作日重新算日薪。出勤仍需确认：整天、半天和缺勤分别计1、0.5、0天，未填不自动算缺勤，未来只作预计。续期不伪造工时或工资到账。
- 历史、已开始或已有出勤／到账的方案不自动改写；尚未开始、未手动编辑且无出勤／到账的自动方案会跟随前一期工资调整。手动改过的未来方案按你的设置保留，后续再沿用它。公司工资变化或周期变化请在「计薪设置」核对，助手不能代确认。
- 暂停保留已生成的方案，恢复后补齐缺少的区间。手动删除的区间不会被续期重建；若要恢复它，可重新手动新建该月份。删除项目最后一期会同时暂停续期。规则和删除排除项随备份恢复。
- 计薪周期尚未确认时显示核对提示；未收录官方假日的年份显示待更新，不以普通周一至周五冒充法定排班。当前内置2026、2027年。收到包含新年度安排的应用更新后继续生成。

## 工时与薪资

- 自然月可能与同一项目的两个工资周期相交（例如 11 月涉及 10.21–11.20 和 11.21–12.20）。现在只显示一张项目卡，卡内「查看计薪区间」切换；不是两份工作，不合并或重复计薪，日历合计仍按顶部所选范围。计薪设置和批量补记只操作卡内当前选中的周期。

在「工时」点日历中的日期，按项目记录当天工作。「按时薪」填小时数，可用项目时薪或默认时薪。「按日薪」填日薪和计薪天数，半天填 0.5，实际工时选填。同一天可有多个项目，也可混合两种计薪方式。日历格展示每日工时与已计工资，点当天记录可编辑，长按记录可删除。「时薪设置」可改项目和默认时薪。

- **月薪按工作日折算**：在「工时 → ＋ 月薪方案」填项目、完整一期正常出勤工资、计薪周期和归属月份。归属月份是区间结束的月份，例如选择“上月21日到本月20日”，2026年10月方案覆盖9月21日至10月20日，下一期从10月21日开始，日期不重叠。可选自然月或22日至次月21日。不确定时保留“暂未确认，先按自然月估算”，助手和首页都会说明区间待确认。
- **入职起算与发薪日**：工资方案填完整「入职起算日」，此前不计薪、不算缺勤。整期应出勤日期仍作分母，首次不足一期按入职后的工作日比例估算。在首页「本期工作／本月工作」底部点「距发薪…」或「今天发薪」可设置每月发薪日，默认21日；它不决定计薪区间、不创建收入，也不是已安排的系统通知。用户只说入职日或发薪日时，不能推断公司的考勤截止日已确认。
- 工作日规则可选「法定节假日及调休」，内置2026、2027年安排，包含调休周末；点日期按公司安排调整。自动续期每期重新生成法定工作日，不照抄上期自定日期；未知年份等待应用收录官方安排，也可暂停续期后手动建方案并核对排班。详见「工资自动续期」。
- 日薪参考值等于完整一期工资除以本期应出勤天数。点工时日历当天的月薪项目，选「出勤一天」「出勤半天」「缺勤一天」。未填的过去日期待确认，未来只作预计，不自动扣钱。预计工资按剩余日期正常出勤估算，已计工资只包含确认记录，完整一期全勤精确等于月薪。金额按累计计薪比例分摊到分，补记早期日期时后续日金额可能微调一分钱。
- 旧固定日薪可在方案中勾选「将区间内同项目的旧日薪重新折算」，核对金额后保存，只转换所选区间。已有月薪方案更改周期时，点「计薪设置」，改周期后进入「预览计薪周期调整」：先查看此项目全部日薪、月薪记录的新区间与金额，再确认。保留工作记录的日期、备注、工时，时薪记录不动；未确认的自定义排班需重新核对。原工资收入保留金额、账户和日期，解除旧周期关联并标记待核对，需要在新周期重新关联，避免自动猜测归属。
- 已有出勤的日期若要从方案移除，先在当天「撤销当天确认」。删除方案会删除其月薪出勤，收入账单保留。月薪卡「批量补记」可多选截至今天且入职后的未记工作日，统一记整天、半天或缺勤，保存前核对数量和金额。同项目同日已有普通记录时先转换或核对。
- 工时页面默认打开第一个「自然月」，第二个是「工资周期」；有工资方案时显示这两个切换项。跨月日历标出完整起止日期，周期首日及每月1日带月份，点当天看明细。按期的工资卡可能与自然月区间不同，始终以卡上的起止日期为准。「项目分布」可切工资、出勤天数和已填小时。
- 「工资到账」按项目和工资归属月份核对，月薪项目使用方案的完整起止日期。「登记到账」选择收款账户及实际到账日期，支持分批；已记过的收入用「关联已有收入」。跨月发薪仍可归属原周期，收入报表按实际到账日统计。点到账可编辑，「解除关联」保留账单，「删除到账」撤回收入及账户影响。未关联的收入不会自动认定已结清。
- 首页「本期工作」精简展示已计工资、已关联到账及待确认出勤，点日期范围可打开工资方案，点待确认天数批量补记，点「核对工资到账」查看待收及到账明细。预计工资、缺勤扣薪等完整信息在工时页工资卡中；无当前方案时显示自然月已记工资和出勤，并提供「设置工资」入口。「本月收支」始终按自然月与实际收付款日期计算，单独于工资估算；待处理区显示近期日程、待办和扣款，更多工具默认折叠。资产页先展示净资产，转账／还款、会员订阅、出差报销共用一行入口；「资产账户」下拉列表默认收起，展开后点账户可核对余额，下方是所选账本的本月收支。
- 助手可离线查询本期或上期工资，逐项目列出起止日期、已计、已关联到账、待收和预计。明确说“自然月”时只汇总该月的工作记录。计薪方案、出勤确认、周期调整和到账关联需用户按上述入口操作，助手不能伪称已修改或重复用普通收入、工时动作代替。

## 订阅扣款与提醒

订阅金额按「每次扣款原价」填写，周期可选每月、每季度、每年。首页和资产按月均折算；暂停订阅不计固定支出。设置下次扣款日，可开启当天或提前 1、3、7 天上午 9 点通知。实际扣款后点「已扣款，登记支出」，核对人民币实扣金额、账户和分类；已经记过的可选择已有支出关联，不会重复记账。保存后推进下次日期，删除最新一期扣款账单可恢复对应待扣日期。删除订阅保留历史扣款账单。

## 时光、备忘与习惯

- 「时光」可切换「日历」「今日」「事项」「更多」。默认大月历铺满主要区域，周一为每周第一天，每格显示公历、农历、节日或节气，最多两条日程／待办摘要；“+N 项”表示还有安排，“◦ 已完成/应打卡”是习惯进度。点击日期后，在下方查看全部安排，点日程或待办名称编辑，点勾选框完成或撤销该天待办，点习惯打卡；未来日期不能提前打卡。每周重复日程的编辑或删除会作用于整条重复安排。
- 月历上方箭头切月，点年月选择月份，点“今天”回到当日，右上角“＋”为选中日期新建日程；当天明细也能添加日程或待办。月底切换会自动取目标月份的最后一天，不会滚到下个月。首页左上日期也能直达今日月历。
- 农历与二十四节气按中国标准时间离线计算，日历浏览支持 1901–2099 年。只内置 2026、2027 年中国大陆官方放假调休：“休”为官方放假日期，“班”为调休上班；普通周末不标休，节日名称不等于放假。其他年份明确提示未收录放假调休，不推测假期；点“农历 · 节假日说明”查看来源。实际企业排班仍在工时页设置，不会因浏览时光日历而修改工资。今日页可完成待办、打卡。事项支持日期、时间、重要或紧急标记、列表与四象限，以及每日、每周或每月重复。
- 日程编辑可开启「手机提醒」，选准时或提前 5、15、30、60 分钟或 1 天。全天日程使用日期输入，包含结束日，可指定开始日的提醒时刻，再按提前量排程；旧全天日程继续沿用原开始时刻，编辑时可核对。每周重复的日程继续提醒；修改、关闭或删除会同步排程。普通日程在次日 00:00 结束时不占次日，跨天日程分开标注开始、跨天和结束；移动开始时间会连同结束时间一起移动、保留时长，结束时间仍可单独调整。日程仍是计划，实际工作在工时页确认。
- 「时光 → 更多」可打开备忘录、习惯打卡、番茄专注、倒数日/纪念日。备忘录支持文本、清单、搜索和置顶。习惯可在打卡月历查看。专注可选番茄钟、正计时或倒计时。倒数日可设每年重复。

## 手机提醒、闹钟与日历

安卓上编辑待办或备忘，填日期和时间，勾选「到时通知我」并保存。收不到时看「我的 → 手机提醒」，检查「通知设置」「准时提醒」。展开「锁屏提醒检查」可查看排程和最近提交通知的时间，运行「一分钟测试」。在支持的手机上，可在编辑页选「另设手机闹钟」或「保存并交给手机日历」，在系统应用里确认；之后改期或取消这些外部提醒也在相应系统应用操作。

## 数据、显示与更新

- 在「我的」展开「数据」。安卓可查看本地自动备份，或点「坚果云自动备份 → 设置」，用坚果云邮箱和第三方应用密码连接。连接后，变动会排队上传，断网后可重试。换机时连接同一账号，选择云端副本并确认恢复。备份包含账单、生活记录和对话，AI Key 留在本机。
- 「导出完整备份」生成 JSON，可在「导入备份」预览并确认恢复。「导出 CSV 账单」用于查看流水。清空本机数据或恢复备份需在界面里确认。
- 「我的 → 显示」可隐藏金额并切换浅色、深色或跟随系统。「我的 → 应用更新 → 检查更新」可检查新版，按「下载并安装新版」后在安卓安装界面确认。

## AI 助手与操作范围

- 离线可问“还有多少报销没到账”“本月工资汇总”“家教结清了吗”“下周有哪些扣款”。报销按全部行程或指定行程，工资按本月或上月已记项目和已关联收入，扣款按已设置的日期查询。查询不执行记账。月薪方案、出勤确认、工资结算关联和订阅扣款由用户按对应界面操作，助手不可用普通收入或工时动作替代这些操作。
- 在「我的 → AI 助手设置」填写接口地址、模型和 API Key，测试连接后保存。联网对话会携带本手册、近期对话及应用提供的数据摘要。助手页可新建、切换和删除历史对话。离线可使用简单记账、月度查账及手册中的操作指引。
- 联网助手能按明确指令记人民币收支、转账或还款、建待办、建文本备忘、建习惯、为已有习惯打今天的卡、记时薪或日薪工时。聊天操作卡可撤销支持的操作。普通待办动作可设日期、重要和紧急；需要具体时间、重复或系统提醒时，再到事项编辑页设置。
- 用户问“在哪”“怎么用”时，直接给出这版界面的按钮和路径。开始或结束出差、登记或删除报销到账、调整汇率、恢复备份、设置手机闹钟等由用户在对应页面操作。解释动作时只给步骤；执行结果以实际保存的记录和操作卡为准。
