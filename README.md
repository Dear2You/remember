# 那年夏天 · 个人生活管理 App

记账 · 工时薪资 · 时光日程 · 打卡 · AI 助手（GLM-5.3），一个 App 全搞定。纯本地存储 + 自动备份，无需登录，个人自用。

## 一、安装到手机

1. 下载 `apk/nianxiatian.apk`（或仓库首页 Releases 说明）传到 Android 手机
2. 点击安装，允许"安装未知应用"权限；要求 **Android 7.0+**
3. 以后更新直接在 App 内操作：**我的 → 应用更新 → 检查更新**（从本仓库在线下载安装）

> 本应用与旧「拾光」是两个独立应用（包名不同），互不影响；旧应用可直接卸载。

## 二、核心功能

| 模块 | 功能 |
|------|------|
| 🏠 首页 | 紧凑收支概览、工作摘要、常用操作、待处理和最近账单；更多工具折叠；导航栏可直接记账 |
| 💰 资产 | 净资产、月收支与预算；资产账户默认收起，点下拉箭头查看与核对；负债可单独展开；支持账户管理与会员订阅。订阅默认新加坡元，支持美元、人民币等 12 种币种。可单独在线更新或手动设置外币汇率，按原价折合人民币汇总。 |
| 🕒 工时 | 七列浅色月历直接显示每日工时和工资。同一天可合记时薪与日薪项目，日薪支持整天、半天及自填天数，实际工时选填。点日期可补记、修改或核对明细。 |
| 📋 账单 | 流水明细、收支分析和账单日历；周/月/年结余；收支折线和分组柱图、分类占比及明细；按同期对比分类变化、查看两期流水；按备注、分类或账户搜索，可直接跳到历史月份。账单日历按日显示支出、收入、收支或结余，可查单日排行和本月剩余预算 |
| ✨ 时光 | 日历（日程+待办+打卡叠加）/ 今日工作台 / 事项四象限 / 番茄专注（真实时间戳）/ 倒数日 |
| 🤖 AI | GLM-5.3 流式对话；**多会话**（新建/切换/删除）；自然语言记账/建待办/记工时，可撤销 |

在「记一笔 → 一句话记账」或助手中输入“昨天微信午饭 28 元”，核对金额、分类、日期和账户后点「确认记账」。可先点「修改」调整。助手也能在本机回答“上月收支”“本月哪类花得最多？”和“本月哪笔支出最大？”，统计范围跟随账单页选定的账本。这些操作都可以离线使用。

在账单页左右滑动可切换流水明细、收支分析和账单日历。在时光页可滑动切换日历、今日、事项和更多。

**自动续期与星空彼岸（v2.34）**　企业上班沿用月薪、计薪周期及入职日，按新一期法定节假日和调休准备下一期，重开应用会补齐缺少的周期。项目卡底部可暂停／恢复，手动删除不重建，出勤与到账仍由用户确认。未知年份提示等待官方数据更新。[续期规则](docs/work-calendar.md)。在「我的 → 显示」选择「星空彼岸」，切换夜蓝星河、雾紫细节与远岸插画；原水墨风格保留。[主题与素材](docs/starry-theme.md)。

**首页与时光月历（v2.33）**　首页统一水墨账页的比例、留白与信息层级；时光使用全宽大月历，显示农历、节日、节气、放假和调休班，以及日程、待办和打卡。点日期直接管理当天安排，支持年月选择、回到今天和全天提醒时刻，修复跨午夜日程多占一天等日期问题。[历法与假日来源](docs/work-calendar.md)。

**手续费、信用消费与输入体验（v2.32）**　账单默认流水明细，收支分析排第二。转账支持额外扣费 / 金额内扣费，预览扣款与到账，费用随转账改删并计入支出。新增购物、外卖、奶茶饮品额度及白条账户入口，下单计消费、还款不重复计算；首页展示信用消费和当前待还。修复 Android 键盘遮挡，长表单自动露出输入栏；水墨浅色界面加强青绿、红色与暖金层次。[规则与使用说明](docs/spending-and-saving.md)。

**水墨与月度计划（v2.31）**　整页浅青水墨背景，底部导航与记账弹窗统一淡彩图标，首页增加月度预算和存钱进度。同一工作项目跨两个计薪区间时合成一张卡，卡内下拉切换。新增全账本月消费上限、每天可花额度、超限核对和存钱目标。默认识别建行卡为主要存钱账户，其他账户优先用于消费；存入、取出同步账户与流水，支持编辑、删除和备份恢复。[统计口径与规则](docs/spending-and-saving.md)。

**手账界面（v2.30）**　首页将日期、山水与收支组合成账页，工作便签与待办／流水列表各有清晰层次。资产账户改为默认收起的下拉列表，账户、操作与账单分类使用统一淡彩图标。备忘录、打卡、倒数日、专注、订阅和设置一并调整；订阅页先显示记录，汇率设置收在「折算汇率与币种」中。金额隐藏、编辑和数据恢复入口保持可用。

**清新山水界面（v2.29）**　主要页面加入浅青山水、柳叶与湖面短页眉，常用操作用淡彩边饰。图表增加轻透的折线填色、渐变柱形、选中提示和细致的分类环形图，收入绿、支出红，深色模式同步适配。保持紧凑的卡片和文字，工时默认自然月；装饰图随 APK 提供，离线可用。[插画素材与生成说明](docs/design-assets.md)。

**紧凑界面（v2.28）**　首页优先展示日常收支及操作，缩减封面、卡片和文字占用。资产页直接看账户与余额，时光日历显示今天的安排，主要页面统一字体与导航。工时默认打开第一个「自然月」，「工资周期」在第二个；计薪数据与规则不变。

**跨月计薪（v2.27）**　工资方案支持自然月、上月21日至本月20日和上月22日至本月21日；独立设置入职起算日与每月发薪日。未知周期沿用原估算，并显示待确认。更改周期先预览记录与金额，再确认转换；工作记录与现金账单保留，旧到账归属需重新核对。首页区分工资估算与自然月收支，工时页可切换工资周期与自然月。

**月薪折算与工资到账（v2.26）**　在工时页切到目标月份，点「＋ 月薪方案」，填写整月工资，按法定节假日及调休预填应出勤日，也可逐日调整。支持整天、半天、缺勤与批量补记，待确认和未来日期不自动扣薪。旧日薪可预览后按月转换，时薪项目独立保留。工资到账可关联已有收入、分批收款、选择账户、编辑、解除关联或删除。日薪项目图支持工资、出勤天数和小时切换。[工作日数据与分摊规则](docs/work-calendar.md)。

支出支持「支付渠道」与「实际扣款账户」，在资产页展开「资产账户」后，点某个账户可核对余额。订阅支持月、季、年周期与续费提醒，登记扣款可关联已有账单。出差支持提交状态、票据照片、单次明细导出。日程可设置提前通知。首页增加工作与收款入口，离线助手可查工资结算、待报销和未来扣款。

出差时在「资产 → 出差报销」新建行程。底部「记一笔」默认记为这次行程的垫付，偶尔有个人消费可取消当笔的「记为出差垫付」。出差结束后关闭出差模式，等待打款期间仍能查看待报销余额。公司打款时在行程内点「登记到账」，金额默认填剩余垫付款，也可改为本次到账金额。垫付和到账更新账户与应收余额，个人收支和预算单独统计。

**手机提醒（安卓）**　在待办或备忘的编辑页选「今天」「明天」或具体日期，填好时间，勾选「到时通知我」后保存。点通知可打开原记录，待办可以直接完成这一次。每日、每周和每月待办会继续提醒，备忘清单全部勾选后会取消提醒。

在「我的 → 手机提醒」可以管理通知权限和准时提醒。普通提醒可能因省电设置延后。系统时钟可接收最近一次该时刻的闹钟，在编辑页点「另设手机闹钟」即可交给时钟，之后由时钟管理。提醒配置随备份恢复，换机后需在新手机允许通知。

如果只在打开应用时收到通知，展开「锁屏提醒检查」核对下一次排程和最近一次向系统提交通知的时间。可开启「系统闹钟排程」并允许「闹钟和提醒」，再点「一分钟测试」回到桌面、锁屏。这个模式会将下一条提醒登记为系统的下一次闹钟，到点仍发送本应用的通知。系统限制后台运行时，请点「应用信息」检查电池或后台设置。使用系统的「强行停止」后需重新打开应用。

如果通知直到返回应用才提交，重要事项可交给手机自带应用。近期响铃可点「另设手机闹钟」，在时钟里确认。指定日期可在待办或备忘编辑页点「保存并交给手机日历」，核对标题、日期、重复方式，在日历中选「开始时提醒」并保存。外部日程由手机日历独立管理，之后改期、取消或完成事项也需在日历处理。「锁屏提醒检查 → 去时钟试响」可单独验证手机时钟到点响铃。

**记账规则**：整数分存储；转账/还款不计收支；信用卡刷卡只计一次支出；净资产=资产−负债；一级分类下钻不重复；月总预算与分类预算两套口径。

## 三、数据安全

- **自动备份**：数据变化后自动写入手机「下载/那年夏天备份/nianxiatian-backup.json」——**卸载 App 也不会丢**
- **坚果云自动备份（安卓）**：在「我的 → 数据 → 坚果云自动备份」输入坚果云邮箱和第三方应用密码。连接后，数据变动会排队上传；后台通过 Android 系统联网任务重试。换机后重新连接，选择云端副本并确认恢复。文件在私人网盘的 NianXiaTian 目录，按设备和月内日期轮换保存，最多 31 份/设备。备份不含 AI Key，网盘应用密码保存在本机加密存储中。
- 手动导出：JSON 完整备份 / CSV 账单（Excel 直开）
- 恢复：在「我的」点开默认收起的「数据」，选择「导入备份」。确认前可以核对文件名、备份时间及记录数量。清空本机数据会取消待写入的本地自动备份，并暂停云端上传。

## 四、AI 配置

我的 → AI 助手 → 填入智谱 BigModel API Key（[open.bigmodel.cn](https://open.bigmodel.cn) 注册获取）→ 测试连接。默认模型 GLM-5.3，可换任何 OpenAI 兼容接口。

## 五、开发与发布

每次更新都维护 [AI 功能手册](app/ai-guide.md)。按界面上的按钮名称写清入口、操作和结果，区分助手能直接执行的动作和需要用户点选的步骤。在「版本记录」最上面加一条本版变化，只有修复也写明修复内容。离线操作指引和联网助手共用这份 Markdown。

改完手册运行 `node tools/build-ai-guide.js`，将生成的 `app/js/ai-guide.generated.js` 一起提交，直接打开网页也能使用。APK 构建会按发布版本校验最新记录并重新生成。联网请求只携带当前版本说明和现行用法，完整历史留在 Markdown 中。

```bash
node tools/serve.js 8765                     # 本地网页调试
USE_RELEASE_ASSET=1 UPDATE_NOTE="更新说明" bash tools/build-apk.sh 2.34   # 版本与手册首条记录一致
```

- 构建生成对应版本的本地 APK、`apk/nianxiatian.apk` 更新包和 `latest.json` 版本清单。
- 应用内检查更新会在 GitHub Raw 与 GitHub API 之间回退。下载时会校验成品 APK 的 SHA-256、包名、签名与版本。若使用 GitHub Release 分发，构建时设置 `USE_RELEASE_ASSET=1`，并在更新 main 分支清单前，将同一份签名 APK 以 `nianxiatian.apk` 上传到对应的 `v版本号` Release。
- 工具链在 `build/toolchain/`（JDK17 + Android SDK 35，不入库）
- ⚠️ `android/keystore.jks` 已被 .gitignore 排除——**绝不能上传，请异地备份**（丢失后无法覆盖升级）
- 仓库需保持 Public（App 匿名读取更新包）
